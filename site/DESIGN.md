# Stenly site visual system

An editorial cover, not a stacked SaaS pitch. User-pinned magazine references override concept alternatives. Preserve the app's waveform symbol; the site has its own typographic voice.

- Ground: warm paper #f4f2e9; ink #25251f; secondary #605f55; hairline #d2d0c4.
- Logo: off-white #f4f2e9 ground with ink #25251f waveform; no green tile. Wordmark retains its small olive #78852a dot. This supersedes the earlier lime app icon. Acid-lime #d2e45c remains only an interaction accent; burnt-red #a13c2b only for the recording indicator.
- Display: self-hosted Instrument Serif (regular and italic), paired with self-hosted DM Sans. Headlines alternate tightly-set grotesk and expressive serif; tracking never below -0.04em.
- Layout: spacious horizontal masthead, oversized centered three-line cover headline, a three-column editorial spread, fine rules, a compact colophon. No floating card grid, decorative gradients, or fabricated social proof.
- Product demonstration: a flat paper note, tabbed Notes/Transcript, explicitly labeled illustrative. A single short waveform settling motion; reduced motion removes it.
- Buttons: ink rectangles with 8px corners; secondary actions underlined. Details/summary provides an accessible, progressively enhanced download picker. Open source is a direct GitHub link; downloads stay primary through stable release asset URLs. Detect OS for both CTAs: Apple + Download (Mac direct asset), penguin + Get it (Linux chooser with configurable distro instructions). Unknown/mobile keep a chooser; Mac retains Other platforms. Logo backgrounds match the off-white page. Subdued olive carries note checkboxes; lime is reserved for interaction emphasis.
- Breakpoints: cover fits normal desktop viewports (1440×900, 1280×800); short viewports scroll rather than clip. Tablet rearranges story and download with note below. Phones read headline → proposition/download → example → supporting features, with natural scroll.
- All font requests are local. No analytics, external scripts, or runtime framework. Browser selection, focus and scrollbars use the same palette.

- Pricing: separate `/pricing/` page linked from the masthead and download copy; homepage stays focused. Editorial pricing table with three columns, no badges, stats, or fabricated proof. Free source build, $10 one-machine lifetime licence with free-meeting trial, and team contact.

Group the discussion into 2–6 topic sections with short headings named after what was actually talked about, in the order it came up. Each bullet carries a complete point with the actual value or conclusion in it. List decisions and action items separately.

This is the built-in default. Edit it to change every note that doesn't use a more specific template, e.g. "Always start with a section called Context".
